## 核心架构：双图系统（Dual-Image Architecture）

每个滤镜条目均提供 **两套独立中英双语代码块提示词**，覆盖光学标本与真人上身 Lookbook：

1. **【光学硬件/解构标本提示词】(Optical Specimen / Hardware Knolling)**：
   - **视觉形态**：90度垂直俯拍或专业微距棚拍（Knolling Flat-lay / Optical Blueprint）；
   - **工艺细节**：陈列经典胶片相机、高透光学镜头透镜组、镀膜反光、开氏温标色阶标尺、柯达/富士胶卷暗盒或闪光灯物理组件，呈现极致工业机械美学，1:1 画幅。
2. **【真人上身效果提示词】(On-Model Worn / Photographic Lookbook)**：
   - **人物设定**：22岁年轻中国女性，清冷骨相大女主（Statuesque Aristocratic Bone Structure），冷白瓷肌微哑光，原生深黑平直骨相眉与朱红淡唇；
   - **动态质感**：精准还原指定感光介质、色彩科学（Color Science）、开氏色温（Kelvin）、高光滚边（Highlight Rolloff）与暗部噪点，真实重力褶皱与毛孔细节，适配 3:4 比例。

## 条目规范结构

每个条目统一严格遵循以下规范：
- **相机/介质**：指定物理硬件机身、感光元件或胶片型号；
- **色温/光影**：物理开氏温标（Kelvin）、布光方式与明暗动态范围；
- **场景氛围**：地道中国美学空间与特定情绪意境；
- **【单品解构/光学标本提示词】**：独立代码块（中英双语，1:1 画幅，展示机身透镜与分色标尺）；
- **【真人上身效果提示词】**：独立代码块（中英双语，3:4 画幅，锁死反塑料负向金句）。
