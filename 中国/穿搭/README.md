## 核心架构：双图系统（Dual-Image Architecture）

每个穿搭条目均提供 **两套独立中英双语代码块提示词**，覆盖商业型录单品图鉴与真人上身 Lookbook：

1. **【单品平铺/解构标本提示词】(Garment Flat-Lay / Knolling Specimen)**：
   - **视觉形态**：90度垂直俯拍（Top-down Knolling / 平铺解构标本）；
   - **布光背景**：中性米白微水泥、素雅哑光细亚麻台面或深色胡桃木案几，搭配顶部专业柔光箱漫射照明与极淡自然投影；
   - **工艺细节**：服装解构平整排列，微距毫发毕现呈现 30 姆米重磅素绉缎的流动水光、宋锦真丝织金的精密经纬、苏工手工盘扣针脚、羊绒双面呢手工暗缝针距，以及陈列于侧的东方玉石配饰与鞋包。
2. **【真人上身效果提示词】(On-Model Worn / Lookbook)**：
   - **人物设定**：22岁年轻中国女性，清冷骨相大女主（Statuesque Aristocratic Bone Structure），冷白瓷肌微哑光，原生深黑平直骨相眉与朱红淡唇；
   - **动态质感**：行走或驻足时的面料真实物理重力垂坠折痕、空气流动拂过发丝、真实皮肤毛孔与微小质感；
   - **场景光影**：苏州园林漏窗竹影、当代美术馆冷灰挑高展厅、北京青砖庭院夜间硬闪、外滩老洋房露台等真实地道光影，适配 3:4 比例。

## 条目规范结构

每个条目统一严格遵循以下规范：
- **本土/日常叫法**：保留地道中文传统/当代专业叫法；
- **时尚/流行流派**：国际通用时尚术语与流派定义；
- **面料工艺与解构细节**：详细拆解面料材质、姆米数、克重、编织纹理、手工缝纫工艺与配饰构成；
- **适用场合与搭配鞋包**：具体中国地标场景环境 + 鞋履款式 + 包袋配饰搭配；
- **【单品平铺/解构标本提示词】**：独立代码块（包含中文专业版与国际英文版，1:1 画幅）；
- **【真人上身效果提示词】**：独立代码块（包含中文专业版与国际英文版，3:4 画幅，锁死反塑料负向金句）。
