> **The Aperture of Optics, The Soul in the Iris.**

## 核心美学哲学：东方留白、历史沉淀与当代静奢

中国篇风格矩阵拒绝粗制滥造的影楼布景，深度解构中国顶级地理地标与文化空间的真实气韵：

1. **古典江南园林之步移景异**：
   - 苏州留园、拙政园、网师园的曲廊漏窗、太湖石假山、临水美人靠与竹影水榭；
   - 东方「借景」、「框景」与「障景」的极致留白构图法。
2. **北方大国帝王宫苑与古都风骨**：
   - 故宫太和殿汉白玉丹墀、红墙黄瓦深宫长街、景山俯瞰中轴线全景；
   - 北京青砖四合院广亮大门、老胡同老槐树与古刹千年银杏。
3. **海派老洋房与当代先锋极简**：
   - 上海外滩万国建筑群花岗岩柱廊、武康大楼船舰转角、法租界老洋房梧桐树影；
   - 挑高十米当代美术馆纯白展厅、清水混凝土光缝与极简雕塑空间。
4. **隐逸茶室与王家卫式浓郁港风**：
   - 幽深私密中式茶堂、明代枯木案几、沉香袅袅与青石水席；
   - 香港90年代深红翡翠双色霓虹街区、老旧唐楼与湿漉沥青路面。

## 架构规范：双图动力学体系（Dual-Image Architecture）

每个风格条目均提供 **两套独立中英双语代码块提示词**：

1. **【空间/场景解构标本提示词】(Architectural Scenography & Blueprint)**：
   - **视觉形态**：1:1 方形画幅，商业级空间与材质解构平铺图谱（Flat-lay / Spatial Blueprint）；
   - **工艺细节**：建筑轴线透视矢量网格、材质标本（汉白玉、青砖、红木、清水混凝土、织金宋锦）、照明色温（2800K~6500K）与空镜质感，8K超清画册。
2. **【真人场景实拍大片提示词】(In-Situ Environmental Portrait)**：
   - **人物设定**：22岁年轻中国女性，清冷骨相大女主，冷白瓷肌，修长挺拔骨相；
   - **动态质感**：人物与宏大空间的真实交互，真实衣料受风摆动，真实毛孔肌理与环境漫射光，锁死反塑料负向金句，3:4 比例。

- **Gemini (Imagen 3)**：长文本镜头光学解析极其精准，物理色温（Kelvin）与焦段透视关系将得到严谨还原；
- **在线调音台**：访问 [Iris Web Studio](https://noahvisualsx.github.io/Iris/) 支持八轨一键混音与剪贴板 `⌘V` 配图持久化。
