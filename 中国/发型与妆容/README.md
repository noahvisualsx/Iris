## 核心美学哲学：骨相立体、冷白瓷肌与东方留白

中国篇妆发彻底颠覆浮夸欧式浓妆与工业假面，深度解构中国顶级名媛与古典仕女的高阶骨相审美：

1. **皮相服从骨相的清冷底妆**：
   - 拒绝死白面具感，追求宛如剥壳鸡蛋般的「冷白半哑光瓷肌」；
   - 原生平直骨相眉与根根分明的自然野生毛流，微蹙如远山青黛；
   - 哑光故宫宫墙红、车厘子深红与干枯玫瑰豆沙唇色。
2. **极简挺拔与非遗玉簪发式**：
   - 贴头皮极简中分低盘发（Clean Girl Aesthetic 与东方大女主融合）；
   - 天然羊脂白玉簪、老坑冰种翡翠发钗斜插的松弛风雅；
   - 90年代王家卫式浓郁蓬松港风侧分大波浪；
   - 刀锋般利落挺拔的先锋高马尾。

## 架构规范：双图动力学体系（Dual-Image Architecture）

每个发型与妆容条目均提供 **两套独立中英双语代码块提示词**：

1. **【妆发动力学解构标本提示词】(Hair & Makeup Anatomy Blueprint)**：
   - **视觉形态**：1:1 方形画幅，商业级美妆与发丝解构图谱（Beauty Flat-lay & Hair Blueprint）；
   - **工艺细节**：头骨黄金比例测量线、发缝中轴对齐度、发丝曲率矢量、色号Pantone标定（如宫墙朱红、远山黛青、象牙冷白），4500K柔光无影漫射，8K超清画册。
2. **【真人妆发上身效果提示词】(On-Model Beauty Lookbook / In-Situ Portrait)**：
   - **人物设定**：22岁年轻中国女性，清冷骨相大女主，五官雕塑般深邃精致，真实毛孔肌理与微小皮脂光泽；
   - **动态质感**：自然发丝飞扬与蓬松质感，真实唇纹与眼波反光，锁死反塑料负向金句，3:4 比例。
