## 核心设计标准

所有条目均严谨遵循 **工业级四段式黄金标准**：
1. **地道本土原语与文化背景**（中文传统/当代专业叫法 + 历史面料工艺背景）；
2. **国际化时尚标签**（English Tags + 权威时装流派定义）；
3. **高精度物理参数拆解**（面料克重与姆米数、织造工艺、相机感光元件、开氏温标 Kelvin、解剖学骨骼肌肉微动态、瞳孔反射光学）；
4. **双图架构提示词（中英双语独立代码块）**：
   - 【单品平铺/解构标本提示词】（1:1 方形画幅，商业级 Flat-lay / 动学微距解构标本）；
   - 【真人上身效果提示词】（3:4 竖向画幅，22岁清冷骨相中国女性，真实毛孔肌理与重力褶皱，锁死反塑料负向金句）。
