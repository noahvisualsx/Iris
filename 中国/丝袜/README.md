# Iris (虹镜) · 中国篇 · 丝袜与腿饰矩阵总览

> **The Aperture of Optics, The Soul in the Iris.**
> 本模块为 Iris 工业级人物视觉系统的核心腿部质感与东方织造支柱「丝袜与腿饰」（Hosiery & Leg Ornamentation），共收录 **60 套中国全场景高阶丝袜面料与非遗工艺矩阵**（#001 - #060），全量升级为面料工程学与摄影工程级的**「双图动力学解构体系」（Dual-Image Architecture）**。

## 核心美学哲学：羊脂玉瓷肌与东方织物骨相

丝袜在中国篇矩阵中绝非轻浮点缀，而是下半身轮廓构建、肤色光学校正与东方古典工艺的承载体：

1. **羊脂玉冷白瓷肌极透质感**：
   - 5D~15D 极薄高密包芯丝，未撑开如温润白玉，撑开后与 22 岁清冷女性冷白瓷肌完美熔铸；
   - 哑光低反光与微水光折射，修饰腿部细微瑕疵，呈现如剥壳鸡蛋般的无瑕骨相。
2. **玄黑透光与深沉层次（10D~30D）**：
   - 拒绝对比度生硬的纯黑死黑，精准控制 10D~30D 丹尼尔数；
   - 迎面骨与膝部在高光下呈现自然冷白透肉，腿侧深沉阴影收拢修长线条。
3. **东方非遗工艺与水墨意象**：
   - 复古中缝水墨竹节线、宋锦织金暗纹提花、手工苏工盘扣与白玉吊坠腿饰；
   - 故宫朱红、深墨绿、青黛色与玄黑渐变，让东方文人意趣跃然于现代织物之上。

## 架构规范：双图动力学体系（Dual-Image Architecture）

每个丝袜条目均提供 **两套独立中英双语代码块提示词**：

1. **【单品平铺/解构标本提示词】(Hosiery Knolling & Textile Blueprint)**：
   - **视觉形态**：1:1 方形画幅，商业级平铺展示（Flat-lay）；
   - **工艺细节**：未拉伸织物微纹理、高弹无痕腰封、T裆/全棉透气裆、足尖隐形加固缝线、色彩Pantone标定色块，4500K柔和无影光，8K超清画册。
2. **【真人上身效果提示词】(On-Model Hosiery Lookbook / In-Situ Portrait)**：
   - **人物设定**：22岁年轻中国女性，清冷骨相大女主，冷白瓷肌，修长挺拔双腿；
   - **动态质感**：真实光线下迎面骨与膝部透光折射，膝弯自然生理折痕，真实面料重力与拉伸张力，锁死反塑料负向金句，3:4 比例。
