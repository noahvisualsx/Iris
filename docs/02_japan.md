# 02. 日本篇 (Japan) —— 视觉全要素控制规范

## 一、 审美文化与视觉基因

日本摄影视觉文化（以川内伦子、奥山由之、木村和平以及《POPEYE》《FUDGE》杂志为代表）强调**「空气感、生活褶皱与瞬时留白」**。

1. **色彩心理**：
   * 追求自然高光泛白微过曝与阴影泛青绿调（Fujifilm Green Shadow）。
   * 画面温润透明，带有淡淡的米黄色调或多云阴天的纯净散射光。
2. **场景语境**：
   * 街角亮着白色暖光的自动饮料贩卖机、电车月台木椅、东京下町坡道与斑马线、二手古着店。

## 三、 招牌姿势动作与人体工学

1. **自动贩卖机旁·下蹲抱膝**
   * *解剖学细节*：双膝收拢紧贴胸口，足尖踮地，双手紧裹热饮罐，面孔向上仰 35 度，展现清澈探索感。
2. **斑马线迈大步·疾走回眸**
   * *解剖学细节*：骨盆朝行进方向，腰部与肩部逆向扭转 70 度回头，长发伴随步伐产生自然的空气飘逸轨迹。
3. **双手捧杯·缩脖呵气**
   * *解剖学细节*：双肩略微前耸，下颌埋进厚重的粗棒针毛线围巾中，微张唇呵出一缕白色雾气。
4. **电车倚窗·侧颜看风景**
   * *解剖学细节*：太阳穴轻贴电车双层强化玻璃，睫毛在日光下投下细碎阴影，眼神放空出神。
