# 04. 美国篇 (USA) —— 视觉全要素控制规范

## 一、 审美文化与视觉基因

美式视觉审美（以加州西海岸、Clean Girl 美学、90 年代街头复古及汉普顿名流预科风为代表）强调**「旺盛的生命力、不加掩饰的自信（Unapologetic Confidence）与阳光感」**。

1. **色彩心理**：
   * 极度偏好浓郁的暖阳金黄（Golden Hour Amber）、高反差原色（丹宁蓝、复古皮棕、番茄红）。
   * 追求皮肤在强光照射下的真实晒痕、水光发亮感与健康毛孔。
2. **场景语境**：
   * 加利福尼亚棕榈树大道、海滩冲浪木栈道、红砖消防逃生梯、深夜复古霓虹 Diner 餐馆、汽车引擎盖。

## 三、 招牌姿势动作与人体工学

1. **高举手机 0.5x 超广角俯拍自拍**
   * *解剖学细节*：单手将手机伸向斜上方 45 度极高位置，身体自然向后倾斜，下巴微扬，另一只手拿着冰咖啡或比出随性手势，眼神充满灵动。
2. **横穿马路·开怀大笑抓拍**
   * *解剖学细节*：双腿步幅极大跨步前行，单手随意插在做旧牛仔裤后兜，整张脸回转向镜头绽放毫不掩饰的开怀大笑。
3. **引擎盖/街角马路牙子席地而坐**
   * *解剖学细节*：屈起单膝，手臂搭在膝盖上，身体呈放松的微弯弓形，毫无防备的生活化姿态。
4. **背靠红砖墙·双臂环胸直视**
   * *解剖学细节*：后背完全倚在粗糙红砖上，双臂交叉抱胸，眼神直视镜头核心，下颌线条利落有力。
