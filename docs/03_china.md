# 03. 中国篇 (China) —— 视觉全要素控制规范

## 一、 审美文化与视觉基因

中国当代人像摄影（以新中式静奢、小红书夜间硬闪大片、港风复古及当代美术馆艺术人像为代表）强调**「骨相结构、清冷从容的大女主气场与东方留白意境」**。

1. **色彩心理**：
   * 极度注重人物轮廓线条与明暗反差。
   * 喜欢将深邃的纯黑背景（夜景/深色水墨背景）与冷白瓷肌、正红唇色构成强烈视觉对话。
2. **场景语境**：
   * 古典青砖黛瓦园林配修竹倒影、胡同朱红大门、当代极简清水灰美术馆、都市夜间高空天台。

## 三、 招牌姿势动作与人体工学

1. **微扬下颌·3/4 侧颜回眸绝杀**
   * *解剖学细节*：肩胛骨展平，颈部胸锁乳突肌微微绷紧显现天鹅颈，下巴向上抬高 10 度，眼神微向下俯视镜头，清冷孤傲。
2. **修长指尖·轻触领口盘扣**
   * *解剖学细节*：手部手腕自然悬垂，中指与食指指尖轻搭在领口温润的翡翠或珍珠盘扣上，姿态松弛但充满克制的贵气。
3. **背对镜头·凭栏极目远眺**
   * *解剖学细节*：背影挺拔，单手搭在汉白玉石栏或极简黑铁栏杆上，仅上身半侧转，侧脸在暗光中勾出利落银线剪影。
4. **阔步走动·大衣带风大女主**
   * *解剖学细节*：大跨步径直朝向镜头走来，单手插在西裤口袋，大衣下摆随风荡起，步履沉稳笃定。
