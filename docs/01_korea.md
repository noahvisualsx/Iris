# 01. 韩国篇 (Korea) —— 视觉全要素控制规范

## 一、 审美文化与视觉基因

韩国当代人像视觉（以首尔圣水洞买手店、弘大街头、汉南洞画廊及韩流明星私服为代表）的核心特征是**「克制的精致与刻意营造的松弛（Effortless Chic）」**。

1. **色彩心理**：
   * 极度忌讳油腻暖黄和脏浊暗部。
   * 追求冷白皮（Cold Porcelain Skin）、灰青调中间调（Muted Blue-Grey Midtones）以及高光轻微泛白透光的陶瓷感。
2. **场景语境**：
   * 现代极简水泥/微水泥室内。
   * 首尔街头灰色沥青地面与纯黑不锈钢门头。
   * 柔和多云天气的街角玻璃窗边。

## 三、 招牌姿势动作与人体工学

1. **双臂微屈·手机半遮面对镜自拍**
   * *解剖学细节*：双手握持手机，手机顶部平齐眉骨，遮挡下巴至鼻尖。肩膀微耸 5 度，视线保持微下垂或斜视镜头。
2. **低头拉防风服拉链/衣领**
   * *解剖学细节*：下巴微收，头顶微向下倾斜 20 度，双手手指捏在拉链金属头上，捕捉不经意的日常生活瞬间。
3. **单手撩发·侧首微俯视**
   * *解剖学细节*：右手食指由前额划过耳际，将碎发挂于耳廓，头颅向左侧倾斜 12 度，露出清晰的下颌折角。
4. **外带咖啡男友 POV 视角**
   * *解剖学细节*：第一人称超近视角，角色单手递送纸质咖啡杯，另一侧肩膀微向后撤，营造自然的亲密互动感。

## 四、 穿搭面料与细节库

* **核心单品**：
  * 精纺羊毛落肩西装外套（深炭灰 / 燕麦冷灰）
  * 纯白高支棉平纹圆领削肩内搭 / 细罗纹修身长袖
  * 极简高腰垂坠西装拖地阔腿裤（面料垂坠感强）
  * 纯黑哑光尼龙防风冲锋衣
* **面料质感要求**：
  * 拒绝一切廉价反光化纤面料。
  * 强调精纺羊毛的哑光毛绒感、重磅纯棉的面料骨力、高密尼龙的微褶皱。
* **配饰标配**：
  * 冷银色细圈钛钢耳环。
  * 极简细黑框板材平光镜。
  * 哑光小牛皮极简托特包。
