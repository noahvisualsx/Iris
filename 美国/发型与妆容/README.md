## 核心美学哲学与发妆理念 (Core Aesthetics Philosophy)

美国当代发型与妆容美学是一场关于**「自由生命力、立体高级骨相、原生皮肤微光与个性反叛」**的视觉交响：

1. **Clean Girl 极简晨光美学 (The Clean Girl Aesthetic)**：
   - 以海莉·比伯（Hailey Bieber）和肯豆（Kendall Jenner）为标杆，崇尚极简贴头皮低发髻（Slicked-Back Bun）、180度精准中分与丝滑芭蕾盘发；
   - 妆容追求“如同刚涂抹完精华”的琉璃水光肌底（Glazed Donut Skin）、羽状向上提拉的肥皂野生眉（Laminated Soap Brows）与饱满多肽玻璃裸粉唇，彻底告别假面厚粉。

2. **加州阳光海滩与小麦晒伤肌 (California Sun-Drenched & Sunkissed Bronze)**：
   - 太平洋西海岸海风自然吹干的粗粝海盐波浪卷（Sea Salt Beach Waves）、金色巴拉亚格手刷挑染（Balayage）与湿发海妖水波纹；
   - 横跨鼻梁与苹果肌的W型健康小麦晒伤腮红（Sunburn Blush）、自然原生感小雀斑与暖铜古铜落日高光，洋溢加州户外的蓬勃健康生机。

3. **美式复古 90s 超模蓬松大波浪与冷艳雕刻妆 (90s Supermodel Blowout & Sculpted Glam)**：
   - 复刻辛迪·克劳馥（Cindy Crawford）与克里斯蒂·特林顿（Christy Turlington）的标志性大号魔术卷吹风（Big Bouncy Blowout）与经典高层次羽毛剪（The Rachel Cut）；
   - 全哑光天鹅绒陶瓷底妆、深巧克力棕色精细唇线搭配裸肉粉唇心、冷灰棕半截断眼窝（Cut Crease）与雕塑感骨相立体修容。

4. **Y2K 千禧辣妹双发辫与未来银河闪片 (Y2K Cyber Nostalgia & Galactic Shimmer)**：
   - 千禧流行乐黄金时期的前卫标志：利落高耸刺猬发髻（Spiky Bun）、翻翘高马尾（Flicked Ends）、前额龙须细麻花小辫与多彩迷你塑料蝴蝶抓夹；
   - 银河泪滴微型碎钻亮片、极光冰霜浅蓝与浅紫珠光眼影、未来金属铬银眼线与超高反光嘟嘟水晶果冻唇。

5. **纽约下东区暗黑高街狼尾切与小烟熏猫眼妆 (Downtown Grunge Wolf Cut & Smudged Cat Eye)**：
   - 纽约下东区与苏豪工业区地下摇滚名流印记：断层剃刀羽化狼尾剪（Shaggy Wolf Cut / Mullet）、前卫漂白隐形眉、黑白双色撞色鲻鱼头与湿发微卷；
   - 宿醉感手揉炭黑微烟熏猫眼、下眼睑内眼角锐利下至、勃艮第酒红暗黑血晕与深黑加仑黑莓哥特丝绒唇。

## 工业级双图架构标准 (Strict Dual-Image Architecture)

本模块 50 组发妆条目均严格执行工业级双图架构标准，全面提供中英双语电影级提示词：

1. **【发型与美妆设计解构提示词 (Salon Blueprint)】 (1:1 方形比例)**：
   - 专业沙龙三视图高定假人头模标本摄影（3-Angle Blueprint, 正面、侧面45度、背面）；
   - 4500K 纯净无影漫射柔光，中性哑光冷灰展台；
   - 精准解构发缝分界几何、发根提拉张力矢量线、波浪卷曲半径公差、剪裁层次厚度阶梯；
   - 侧展台平铺对应妆容的核心化妆品标本：透气粉底液薄层推开展片、腮红修容渐变晕染板、眼影质感微距颗粒剖面与唇膏截面，附带标准 PANTONE 色卡标尺与三维微米工程测量线。

2. **【真人实拍妆发效果提示词 (In-Situ Lookbook)】 (3:4 黄金竖屏人像画幅)**：
   - 22 岁年轻美国女性，拥有加州健康暖金小麦肌或清透冷白微光肌底，立体骨相，优越下颌线与深邃轮廓；
   - 真实自然皮肤质感：保留真实面部微小毛孔、天然绒毛、微小肌理呼吸感与真实生活自然微红润；
   - 真实自然发丝动力学：保留根根分明的发丝质地、空气飘逸感、微细飞扬发丝（Flyaway Hair Fibers）与重力自然垂坠；
   - 锁死反塑料渲染负向约束（Anti-Plastic Negative Safeguards）：严禁假发感、假人面具感、AI 打蜡塑料平滑皮、3D 建模渲染与过度商业修图。
