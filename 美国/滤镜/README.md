每个滤镜条目均提供严格配对的双影视级提示词：
1. **【光学标本/色卡解构提示词 (Optical Blueprint)】 (1:1 正方形比例)**
   - 专业光学标本与色彩解构摄影，90度垂直俯拍（Knolling Flat-lay）
   - 中性哑光微纹理摄影展台，均匀漫射柔光
   - 精确拆解光学硬件与色彩结构：实体胶片相机机身、镜头切片透镜组、35mm/120胶片底片长条、开尔文色温滤镜片、棱镜色散光谱与 PANTONE 色相校准阶梯
   - 中英双语代码块，支持 Midjourney、Flux 与 SD 商业画册级出图
2. **【真人实拍人像效果提示词 (In-Situ Lookbook)】 (3:4 竖屏黄金人像比例)**
