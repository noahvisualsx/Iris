## 核心美学哲学 (Core Aesthetics Philosophy)

美国视觉矩阵以**自由阳光、真实质感与野性生命力**为灵魂底色：

## 核心设计标准 (Core Engineering Standards)

所有条目均严格执行**工业级五星标准与双图架构 (Strict Dual-Image Architecture)**：
1. **地道美式原生语境 (American Native Terminology)**：
   全量采用美式本土日常潮流术语（如 `Clean Girl Aesthetic`、`Athleisure`、`Biker Chic`、`Downtown Girl`、`Model Off-Duty`），并提供深度中文解析与流行背景。
2. **双图架构严密对应 (Dual-Image Blueprint & Lookbook)**：
   - **【单品平铺/解构标本提示词】 (1:1 Aspect Ratio)**：Knolling Flat-lay 俯拍解构，中性哑光展台，面料未经拉伸的真实物理张力、织物纤维克重、色彩潘通色板与辅料五金微距拆解。
   - **【真人上身效果提示词】 (3:4 Aspect Ratio)**：22 岁年轻美国女性，加州阳光健康蜜色肌肤（Sun-kissed Golden Radiant Complexion），优越立体骨相与匀称身形，自然重力垂坠与真实动态褶皱，杜绝假面塑料感与 AI 磨皮假人。
3. **双语自然叙事流 (Bilingual Fluid Photographic Narrative)**：
   每个条目均完整提供**专业级原生美式英语提示词 (American English)** 与 **专业级流畅中文提示词 (Chinese)**。绝对禁止机械式冒号标签（如严禁出现“发型：”、“穿搭：”），绝对禁止在提示词内容中夹带 Markdown 加粗星号（`**`），全部采用电影级光影、实体相机参数与物理面料流体叙事。
4. **反塑料感真实性负向硬约束 (Anti-Plastic Negative Safeguards)**：
   全量在提示词内置原生毛孔肌理、细微面料毛羽、动态微模糊、环境暗部噪点，全面封杀 3D 渲染、塑料芭比感、动漫化脸部与商业过度精修。
