## 核心架构：双图系统（Dual-Image Architecture）

每个穿搭条目均提供 **两套独立代码块提示词**，覆盖商业型录单品图鉴与真人上身 Lookbook：

1. **【单品平铺/挂拍形态提示词】(Garment Flat-Lay / Knolling Specimen)**：
   - **视觉形态**：90度垂直俯拍（Top-down Knolling / 플랫레이）或极简原木衣架挂拍；
   - **布光背景**：极简米白细亚麻布、微水泥摄影台或天然浅橡木地板，搭配高位柔光箱柔和漫射照明与极淡自然投影；
   - **工艺细节**：服装解构平整排列，毫厘毕现呈现外套挺括驳头缝线、细坑条针织纹路、百褶裙锐利刀折、拉链五金电镀光泽，以及对称陈列的鞋履、包袋与配饰。
2. **【真人上身效果提示词】(On-Model Worn / Lookbook)**：
   - **人物设定**：22岁年轻女性，冷白皮（Cold-White Skin），清冷神颜，自然骨相与优越头身比；
   - **动态质感**：行走或站立时的面料真实重力垂坠感、微风吹拂的空气感、皮肤细小微纹理与发丝自然飞扬；
   - **场景光影**：首尔圣水洞工业砖墙、汉南洞私密画廊、三清洞银杏落叶、延世大学红砖草坪等真实地道环境光影，适配 3:4 比例。

## 条目规范结构

每个条目统一严格遵循以下六段式工业标准：
- **本土/日常叫法**：保留纯正韩语原名与韩国圈内惯用词；
- **时尚/流行流派**：国际通用时尚术语与流派定义；
- **单品构成与面料工艺细节**：详细拆解外套、内搭、下装面料克重、支数、针法、压褶与五金拉链；
- **适用场合与搭配鞋包**：具体首尔地标场景环境 + 鞋履款式 + 包袋配饰搭配；
- **【单品平铺/挂拍形态提示词】**：独立代码块，开箱即用的静态平铺解构提示词；
- **【真人上身效果提示词】**：独立代码块，开箱即用的真人 Lookbook 动态提示词。
