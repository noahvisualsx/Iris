## 核心设计标准

所有条目均采用**工业级四段式黄金标准**：
1. **地道本土原语与文化背景**（韩语原文 + 分类由来 + 场景背景）
2. **时尚/爱豆圈流行标签**（国际化风格流派 + 视觉标签）
3. **高精度物理参数拆解**（相机硬件、光学色温、面料克重支数、解剖学肢体工学）
4. **即时可复制代码块**（适配 **ChatGPT (Image 2.5)**、**Seedream 5.0 Pro (豆包)** 与 **Gemini (Imagen 3)**）

## 任意组合示例 (调音台机制)

从 4 个文件夹中各挑一个编号组合即可瞬间合成一组独一无二的顶级大片：

> **`[滤镜 #001 千禧IXY硬闪]` + `[姿势 #001 双手持机半遮脸]` + `[穿搭 #001 韩系女高春秋校服]` + `[风格 #079 人生四格大头贴]`**
>
> 出来的成片就是极其纯正、毫无塑料假人感的**首尔千禧女高复古大头贴生图**！
