## 核心设计标准

所有条目均采用**工业级四段式黄金标准**：
1. **地道本土原语与文化背景**（韩语原文 + 分类由来 + 场景背景）
2. **时尚/爱豆圈流行标签**（国际化风格流派 + 视觉标签）
3. **高精度物理参数拆解**（相机硬件、光学色温、面料克重支数、丹尼尔数 Denier、解剖学肢体工学、瞳孔眼神光）
4. **即时可复制代码块**（专为 **ChatGPT (Image 2.5)**、**Seedream 5.0 Pro (豆包)** 与 **Gemini (Imagen 3)** 优化，直接粘贴出图）
