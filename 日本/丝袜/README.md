## 核心架构：双图系统（Dual-Image Architecture）

每个丝袜条目均提供 **四套独立代码块提示词**（单品静物标本日文/中文 + 真人实拍上身日文/中文）：

1. **【单品静物标本提示词】(Knolling Flat-lay Specimen Blueprint)**：
   - **视觉形态**：90度垂直真俯拍平铺（Top-down Knolling / フラットレイ），中性冷灰哑光极简展台，1:1 正方画幅；
   - **纺织工艺解构**：全解剖式平展呈现未拉伸状态下的丝袜织物，毫厘毕现展示 Denier 纤度编织微观纹理、高弹无痕腰封抗卷边结构、平缝棉质裆部与双层加固足尖暗缝工艺；
   - **商业画册质感**：4500K 柔和漫射无影冷光，极淡自然接触投影，纯净无杂质的高阶织物解剖摄影。
2. **【真人上身效果提示词】(In-Situ On-Model Worn / Portrait)**：
   - **人物设定**：22岁年轻日本女性，典型端庄内双眼眸（奥二重），清透冷白肌，头小脸小优越骨相，双腿修长笔直；
   - **日系发肤细节**：微湿濡发感（濡れ髪）齐肩发丝，轻盈日系空气刘海（シースルーバング），双颊天然通透血色感腮红；
   - **生理透光与折痕**：真实记录丝袜受腿部骨骼肌肉拉伸时的微观透光渐变，迎面骨与膝盖处自然透出冷白肤色微光，膝窝处保留天然生理微折痕，严格禁止二次元假腿感、3D建模假面与塑料渲染，3:4 竖向画幅。
