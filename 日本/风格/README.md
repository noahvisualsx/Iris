## 核心架构：双图系统（Dual-Image Architecture）

每个风格条目均提供 **四套独立代码块提示词**（空间材质解构标本日文/中文 + 真人实拍风格效果日文/中文）：

1. **【空间与材质解构标本提示词】(Spatial Aesthetics & Architectural Material Blueprint)**：
   - **视觉形态**：国际建筑设计与室内空间美学超微距解构摄影（Architectural Material Blueprint），中性冷灰哑光极简展台，1:1 正方画幅；
   - **建材解剖与光谱分析**：全解剖平展该空间的核心建筑建材样块（如老清水混凝土试块、老桧木古材、和纸组子、红砖、不锈钢）、环境光光谱反射率特征、色温比色卡与建筑几何尺寸标尺；
   - **工程画册质感**：4500K 柔和漫射无影冷光，极淡自然接触投影，毫厘毕现物理微观材质肌理。
2. **【真人实拍风格效果提示词】(In-Situ On-Model Worn / Candid Snapshot)**：
   - **人物设定**：22岁年轻日本女性，典型端庄内双眼眸（奥二重），清透冷白肌，头小脸小优越骨相；
   - **日系发肤细节**：微湿濡发感（濡れ髪）齐肩发丝，轻盈日系空气刘海（シースルーバング），双颊天然通透血色感腮红；
   - **空间真实呼吸感**：人物自然松弛融入该特定空间环境（涩谷十字路口、神保町古书店、山手线电车、镰仓由比之滨、和室榻榻米等），光影氛围与色温自然交融，记录衣物面料真实的重力垂坠折痕，50mm 定焦镜头浅景深，严格杜绝二次元手绘、动漫感与 3D 渲染塑料假面，3:4 竖向画幅。
