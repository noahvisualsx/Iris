## 双图核心架构标准

本模块所有预设均严格遵循工业级 **双图提示词架构（Dual-Image Architecture）**：

### 1. 【沙龙发型与美妆设计解构提示词】（1:1 标本解构图）
- **画幅比例**：`1:1`
- **视觉主体**：美发沙龙假发人台剪裁几何展开图、发丝微观束感与毛鳞片质感、剪刀羽化角度、彩妆色粉与液体粉底液试色微距扩散标本。
- **布光规范**：`4500K` 专业沙龙无影漫射柔光，冷灰极简哑光展台，保留极淡天然接触投影。

### 2. 【真人实拍妆发效果提示词】（3:4 真实人像摄影）
- **画幅比例**：`3:4`
- **模特规范**：22岁年轻日本女性，典型端庄内双眼眸（奥二重），清透微光冷白皮，头小脸小优越骨相，下颌线条利落清晰。
- **质感约束**：真实还原额前发际线细软胎毛碎发、原生皮肤微观毛孔肌理与唇部微润光泽；严格锁死反塑料咒语，彻底剔除3D建模面具感与假发套感。
- **摄影参数**：`50mm` 定焦镜头浅景深虚化，日系电影级自然光线抓拍。
