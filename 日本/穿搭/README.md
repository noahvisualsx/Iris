## 核心架构：双图系统（Dual-Image Architecture）

每个穿搭条目均提供 **四套独立代码块提示词**（单品平铺日文/中文 + 真人实穿日文/中文），全面覆盖商业型录解构图鉴与生活纪实 Lookbook：

1. **【单品平铺/挂拍形态提示词】(Garment Flat-Lay / Knolling Specimen)**：
   - **视觉形态**：90度垂直真俯拍（Top-down Knolling / フラットレイ），全解剖解构式陈列；
   - **布光背景**：极简米白细亚麻布摄影台，搭配顶部大型柔光箱漫射均匀照明与极淡自然阴影；
   - **工艺细节**：服装解构平整排列，毫厘毕现呈现纯羊毛麦尔登呢、粗棒针阿兰花纹、天然水牛角扣、博多织真丝光泽、防水压胶机能细节与古着做旧包浆。
2. **【真人上身效果提示词】(On-Model Worn / Lookbook)**：
   - **人物设定**：22岁年轻日本女性，内双或微窄双眼皮（奥二重），透明感冷白微光肌，小脸优越骨相；
   - **动态质感**：带有天然湿润束感的齐肩发梢（濡れ髪），轻盈日系空气刘海（シースルーバング），双颊天然通透血色感腮红，衣物在行走时的重力真实垂坠折痕；
   - **场景光影**：神保町古书店街、下北泽红砖窄巷、代官山现代庭院、镰仓湘南海滨等日本真实地道环境光影，适配 3:4 竖向画幅。

## 条目规范结构

每个条目统一严格遵循以下标准架构：
- **本土/日常叫法**：纯正日语原文（日本語原文）与日本圈内惯用潮流名词；
- **日文标签与流派**：国际通用时尚术语与流派定义；
- **单品构成与面料工艺细节**：详细拆解外套、内搭、下装面料克重、支数、针法与五金辅料；
- **适用场合与搭配鞋包**：具体日本地标场景环境 + 鞋履款式 + 包袋配饰搭配；
- **【单品平铺/解构标本提示词】（日本語）**：独立代码块，原生日语 Knolling 俯拍解构提示词（1:1）；
- **【单品平铺/解构标本提示词】（中文）**：独立代码块，开箱即用的中文 Knolling 俯拍解构提示词（1:1）；
- **【真人上身效果提示词】（日本語）**：独立代码块，原生日语 Lookbook 动态生活写真提示词（3:4）；
- **【真人上身效果提示词】（中文）**：独立代码块，开箱即用的中文 Lookbook 动态生活写真提示词（3:4）。
