## 核心美学哲学：木漏れ日の空気感与日常の断片

日本视觉体系植根于东方幽玄、侘寂（Wabi-Sabi）与现代城市漫游（City Girl / City Boy）哲学的深层交汇，拒绝过度修饰、高反差塑料感与工业刻板摆拍：

1. **木漏れ日の空気感 (Komorebi & Ambient Air)**：
   强调阳光透过树梢枝叶洒下的细碎光影、5200K~5800K 的自然柔和色温与透气的高光漫射。空气中有真实的微尘粒子、清晨的微凉雾气与黄昏的余温。
2. **日常の断片 (Fragments of Everyday Life)**：
   捕捉非定格、无防备的生活瞬间。街角不经意的回眸、下北泽二手书店翻动页面的专注、吃冰淇淋时的微赧一笑、电车月台等待时的沉静放空，呈现纯正日系电影与生活纪实（Daily Documentary）的呼吸感。
3. **シティガール (City Girl & Fudge Aesthetic)**：
   融合《POPEYE》、《FUDGE》、《CLUEL》的松弛叠穿美学。牛津纺衬衫内搭白T、宽松廓形工装裤、重磅粗花呢外套、复古牛津鞋与经典双肩包，呈现雌雄莫辨的盐系洒脱与学院知性。
4. **富士胶片与写ルンです原生光学质感 (Fujifilm Optics & QuickSnap)**：
   精确调校富士胶片独特的绿色阶表现力（Classic Neg、Provia、Astia、Velvia），搭配一次性相机（写ルンです）的广角塑料镜片微桶形畸变、边缘轻微色散与机顶暖色弱闪光灯，赋予画面天然的怀旧情绪颗粒。
5. **奥二重・透明感・濡れ髪・シースルーバング (Authentic Facial Dynamics)**：
   人物设定锁定 22 岁年轻日本女性。拥有原生内双或微窄双眼皮（奥二重）、透亮如玉的薄透冷白微光肌（透明感）、带着天然发油湿润微束感的发梢（濡れ髪）与轻盈微风拂面的日式空气刘海（シースルーバング），彻底告别网红假面与3D渲染塑料感。

## 核心设计标准

所有条目均严格遵循 **工业级四段式黄金标准** 与 **严格双图架构（Dual-Image Architecture）**：
1. **本土地道原语与文化背景**：保留纯正日语原文（日本語原文）与日本圈内惯用潮流名词；
2. **国际化标签与流派定义**：涵盖国际通用时尚摄影流派、光学介质与视觉标签；
3. **高精度物理参数拆解**：相机硬件型号（Fujifilm X-Pro3、Nikon FM2、CONTAX T3 等）、光学色温开尔文、面料克重与织法、解剖学视线角与眼神光反射；
4. **双图架构独立代码块**：每个条目提供两个独立代码块，无缝支持日语原生指令与中文指令一键复制：
   - 【单品平铺/解构标本提示词】（1:1 方形画幅，商业级 Knolling 俯拍或微表情动力学解构）
   - 【真人上身效果提示词】（3:4 竖向画幅，22岁日本年轻女性，真实皮肤纹理、毛孔与重力垂坠折痕，彻底封杀二次元、动漫与3D塑料感）
