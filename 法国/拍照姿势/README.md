## 核心美学哲学与肢体语言

法国摄影中的肢体姿态与摆拍（Pose）恪守**「无摆拍感（Unposed / Candide）、身体与重力的自然沉降、不迎合镜头的冷淡松弛」**：

1. **重心自然塌陷（Collapse of Gravity）**：
   - 彻底告别影楼式挺胸收腹与刻意展露曲线的僵硬感；
   - 脊椎保持自然的微微含胸（Le dos voûté chic），单肘受力托腮，双肩自然沉降，身体重量完全交给椅子、栏杆或地板。

2. **不迎合镜头的第三者抓拍视角（Fly-on-the-wall Perspective）**：
   - 身体与面孔往往处于生活中的真实进行时：漫步中回头、嘴咬发夹挽发、低头看书、翻找包中钥匙、向窗外吐烟；
   - 眼神与肢体很少向摄影师谄媚，营造出如同戈达尔或侯麦电影摄影机偷窥日常的无造作感。

3. **双图工业级标准架构**：
   - **【人体工学与动态骨骼动势解构标本提示词】（1:1 方形）**：中性冷灰背景，医学美学级人体力学与三维动势线标本，关节屈曲角度、重力线倾斜轴向分析；
