## 核心美学哲学与材质工艺

法国丝袜与腿饰美学恪守**「微妙透肤感（Transparence délicate）、经典中缝线几何结构（Couture arrière）、低反光哑光质感与不妥协的优雅」**：

1. **厚度与透光控制（Denier Optics）**：
   - 彻底拒绝廉价油亮反光与塑料假肢感，推崇 10D~20D 极透蝉翼微透黑（Voile transparent）、40D~60D 柔雾烟灰与高定纯黑哑光；
   - 迎光面呈现自然健康的冷白肤色透光，侧面阴影深浅过渡细腻柔润，膝盖弯曲处保留真实的生理微折痕。

2. **法式高级定制经典元素**：
   - **后中缝线（Bas couture avec couture arrière）**：从脚跟沿小腿中心笔直延伸的立体织线，拉长腿型线条，源自20世纪巴黎黄金时代的法式优雅象征；
   - **波点薄纱（Plumetis）与微网眼（Micro-résille）**：左岸知性浪漫的微距纹理，低调含蓄；
   - **南法钩花与古典大腿袜（Bas autofixants en dentelle）**：普罗旺斯复古浪漫的蕾丝花边与高弹硅胶防滑无痕织造。

3. **双图工业级标准架构**：
   - **【单品平铺/解构标本提示词】（1:1 方形）**：纯正商业静物俯拍（Flat-lay），未拉伸状态与局部微距织物物理纹理，无痕高弹腰封、棉质裆部与足尖隐形加固工艺；
   - **【真人上身效果提示词】（3:4 竖画幅）**：22岁年轻法国女性，立体清秀骨相，修长匀称双腿，真实重力褶皱与透光微光，锁死反塑料渲染负向金句。
