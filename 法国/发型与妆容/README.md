## 核心美学哲学与发妆理念

法国发型与妆容美学恪守**「原生微瑕（Beauté imparfaite）、刚睡醒蓬松感（Bedhead Hair）、宛如无妆的呼吸肌底（No-makeup makeup）与随性的红唇」**：

1. **发型哲学：漫不经心的空气结构（Laissez-faire）**：
   - 彻底拒绝死板的沙龙定型喷雾与僵硬卷度；
   - 追求刚从枕头上醒来的自然空气感卷度（Cheveux saut du lit）、随微风自然分列在额角两侧的八字空气刘海（Frange rideau）、随手用玳瑁抓夹或一支铅笔盘起的低发髻。

2. **妆容哲学：无粉底感的透气呼吸肌（Le Teint Nu）**：
   - 拒绝大面积假面遮瑕与千篇一律的水光厚粉，拥抱鼻梁处自然的细小浅雀斑与微血管红润；
   - 原生野生浓眉（Sourcils naturels au savon）、睫毛膏轻刷根部、以指腹点涂的浆果色咬唇（Bouche mordue）与经典法式复古哑光红唇。

3. **双图工业级标准架构**：
   - **【发型与美妆设计形态提示词】（1:1 方形）**：沙龙造型设计三视图（3-Angle Blueprint），假人头模全方位展示剪裁层次与发流走向，侧展台陈列唇膏抹面、粉底质地与色卡标尺；
   - **【真人实景发妆大片提示词】（3:4 竖画幅）**：22岁年轻法国女性，立体高级骨相，深棕色微卷Bedhead长发，真实毛孔呼吸感与原生雀斑，锁死反塑料渲染负向金句。
