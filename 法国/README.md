## 审美文化与核心视觉哲学

法国视觉审美（以让·吕克·戈达尔、埃里克·侯麦、阿涅斯·瓦尔达、简·伯金及当代巴黎代表 Jeanne Damas 为核心）恪守**「漫不经心的优雅（Laissez-faire / Je ne sais quoi）、无粉底感的真实微瑕与左岸知识分子文艺底色」**：

1. **色彩与质感哲学**：
   - 彻底拒绝过度修饰、夸张磨皮美颜与千篇一律的塑料假面感；
   - 拥抱巴黎阴天的中性暖灰漫射（Lumière diffuse parisienne）、奥斯曼建筑斑驳石灰石色调、微泛旧黄的咖啡馆老木纹与经典法式红蓝白低调碰撞；
   - 尊重肌肤真实呼吸感：原生微瑕纯净裸妆、鼻梁间极淡自然小雀斑、晨起微乱的法式八字刘海睡发质感（Bedhead Hair）。

2. **光学与镜头流派**：
   - 法国新浪潮 16mm 粗颗粒电影胶卷（Nouvelle Vague 16mm, ARRI 16SR3, Kodak Vision3 7219）；
   - 巴黎午后灰调漫射（Leica M6, Summicron 35mm f/2）；
   - 维米尔百叶窗边逆光油画感明暗对比（Chiaroscuro, Canon F-1, 50mm f/1.4）；
   - 沿街小酒馆双反玻璃双重透明倒影（Rolleiflex 2.8F, 120胶卷）；
   - 塞纳河畔纪实黑白人文影调（Kodak Tri-X 400, Leica MP）。

3. **空间与生活语境**：
   - 圣日耳曼大道双叟咖啡馆（Les Deux Magots）与花神咖啡馆（Café de Flore）沿街编藤椅；
   - 塞纳河畔绿色墨绿铁皮二手书摊（Bouquinistes de la Seine）；
   - 普罗旺斯薰衣草田与石头村庄粗粝阳光；
   - 巴黎老公寓人字拼橡木地板与雕花铸铁阳台。

## 核心设计标准

所有条目均采用**工业级四段式黄金标准与双图架构**：
1. **地道本土原语与文化背景**（法语原生术语 Français + 历史文化渊源 + 视觉流派标签）
2. **高精度物理参数拆解**（经典胶片相机硬件型号、镜头焦段、开尔文色温、织物支数与克重、解剖学微表情动力学）
3. **【单品平铺/解构标本提示词】（1:1 方形）**：俯拍整齐排列 Knolling Flat-lay 或医学美学级眼部与视线动力学解构标本
4. **【真人上身效果提示词】（3:4 竖画幅）**：22岁骨相优越的年轻法国女性，微凌乱深棕发与自然雀斑，真实重力褶皱与透光质感，锁死反塑料渲染负向金句
