> **The Aperture of Optics, The Soul in the Iris.**

---

## 光学流派与美学基因

法国视觉光学（以让·吕克·戈达尔、埃里克·侯麦、让-皮埃尔·梅尔维尔及柯达经典黑白胶片为代表）追求**「漫不经心的真实光影、无硬光的漫射包裹感与新浪潮 16mm 独特胶片呼吸感」**：

1. **高光与阴影哲学**：
   - 彻底拒绝数码时代的过度锐化与刺眼机顶硬直闪；
   - 拥抱巴黎阴天中性暖灰漫射（Lumière diffuse parisienne），高光丝滑柔和无硬边过渡，暗部保留丰富细腻的中间调层次与深邃微蓝青灰；
   - 百叶窗与雕花铁栏杆投射出的维米尔明暗对照（Chiaroscuro），如古典油画般将光束洒在发丝与肌肤边缘。

2. **核心硬件与经典介质**：
   - **新浪潮电影感**：ARRI 16SR3 / Aaton XTR 16mm 摄影机搭配 Kodak Vision3 7219 / 7207 胶卷；
   - **巴黎人文漫射**：Leica M6 / Leica MP 搭配 Summicron 35mm f/2 经典双高斯镜头；
   - **百叶窗侧逆光油画**：Canon F-1 / Contax RTS III 搭配 Zeiss Planar 50mm f/1.4 温暖泛光头；
   - **双反橱窗双重倒影**：Rolleiflex 2.8F (Planar 80mm f/2.8) 120 中画幅正方形视差叠加；
   - **左岸黑白人文纪实**：Kodak Tri-X 400 与 Ilford HP5 Plus 高感粗颗粒银盐乳剂；
   - **南法地中海艳阳**：Kodak Portra 400 / Ektachrome 100 鲜明暖黄与微过曝金青反光。
