## 核心美学哲学与生活道具

法国摄影中道具与手部细节的美学恪守**「日常生活的有机诗意（Poésie du quotidien）、拒绝塑料工业品、天然材质手作痕迹与原生态指尖质感」**：

1. **道具哲学：真实巴黎生活的呼吸延长线**：
   - 刚出炉外皮焦脆金黄的传统法棍面包（Baguette de tradition）插在牛皮纸袋中；
   - 简·伯金经典的纯手工柳条草编菜篮（Panier en osier）；
   - 翻卷起毛边的伽利玛出版社旧平装书（Livre de poche Gallimard）；
   - 巴黎咖啡馆厚壁浓缩白瓷杯、细长郁金香水晶红酒杯、玳瑁抓夹与复古打火机。

2. **美甲哲学：纯净原生裸粉与法兰西经典正红**：
   - 彻底拒绝繁复水钻与夸张贴片甲，推崇修剪干净整齐的短圆甲型（Ongles courts soignés）；
   - **原生微光裸粉（Vernis nude transparent）**：透出健康的粉白半月牙与甲床微光，天然纯净；
   - **经典黑红与勃艮第深红（Rouge Noir Chanel / Bordeaux）**：短指甲涂抹纯色哑光或高光深红，优雅利落。

3. **双图工业级标准架构**：
   - **【道具与美甲单品形态提示词】（1:1 方形）**：纯正商业静物俯拍与微距标本（Still Life Specimen），中性冷灰展台柔光，微距解构材质肌理与光影；
