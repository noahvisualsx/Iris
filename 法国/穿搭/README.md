## 核心架构：双图系统（Dual-Image Architecture）

每个穿搭条目均提供 **两套独立代码块提示词**，覆盖商业型录单品图鉴与真人上身 Lookbook：

1. **【单品平铺/挂拍形态提示词】(Garment Flat-Lay / Knolling Specimen)**：
   - **视觉形态**：90度垂直俯拍（Top-down Knolling / Mise à plat）或古典法式胡桃木复古衣架挂拍；
   - **布光背景**：极简燕麦色粗织亚麻布、浅灰石灰石台面或古典法式人字拼橡木地板，搭配柔和天光与漫射柔光箱，保留真实织物纤维纹理与极淡投影；
   - **工艺细节**：服装解构平整排列，毫厘毕现呈现法式海魂衫一字领收口、茶歇裙法式裹身系带、粗花呢西装人字纹理与金币扣光泽，以及手工编织草编篮、法式芭蕾鞋与复古皮具。

2. **【真人上身效果提示词】(On-Model Worn / Lookbook)**：
   - **人物设定**：22岁年轻法国女性（Une jeune femme française de 22 ans），骨相立体清秀，微卷凌乱深棕色法式八字刘海卷发（Bedhead texture），原生微瑕纯净裸妆与鼻梁极淡细微雀斑；
   - **动态质感**：行走在巴黎青石板路上时亚麻与真丝的自然重力垂坠、微风穿透面料的空气感、皮肤细小肌理与发丝自然飞扬；
   - **场景光影**：圣日耳曼大道露天咖啡馆、塞纳河二手书摊、卢森堡公园林荫道、普罗旺斯橄榄树下、奥斯曼古典公寓雕花铸铁阳台等真实环境光影，适配 3:4 竖构图。

## 条目规范结构

每个条目统一严格遵循以下标准：
- **本土/日常叫法**：纯正法语原生名词（如 Marinière, Robe portefeuille, Lin lavé）；
- **时尚/流行流派**：国际通用时尚术语与法式美学流派定义；
- **单品构成与面料工艺细节**：详细拆解外套、内搭、下装面料克重、支数、织法、垂坠感、压褶与手工配件；
- **适用场合与搭配鞋包**：具体法国地标场景语境 + 鞋履款式 + 包袋配饰；
- **【单品平铺/挂拍形态提示词】**：独立代码块，1:1 方形商业静物平铺解构提示词；
- **【真人上身效果提示词】**：独立代码块，3:4 竖向写实生活抓拍提示词（含反塑料负向金句）。
